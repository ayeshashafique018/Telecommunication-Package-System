# Telecommunication Package System

## 📌 Project Overview
The **Telecommunication Package System** is a C++ project designed to provide a comprehensive management system for telecom users. It allows users to **check balance, top up, and subscribe or unsubscribe from different telecom packages** easily. The system is user-friendly and includes essential features such as **sign-up and login functionalities**.

---

## 📖 Features
- **Signup & Login System** 🔐  
- **Balance Inquiry** 💰  
- **Top-up Balance** 📥  
- **Package Subscription & Unsubscription** 📞📶✉️  
- **Prepaid & Postpaid Package Selection**  
- **User-Friendly Interface with Console Beautification**  
- **File Handling for Data Storage** 📂  

---

## 🔧 Technologies Used
- **Programming Language:** C++  
- **IDE:** Visual Studio / Any C++ Compiler  
- **Concepts Used:** Loops, Functions, Switch Cases, File Handling, Structs, Enums, and Recursion  

---

## 📑 Modules
### **1️⃣ Sign Up**
- Users register by entering their **name, phone number, and password**.
- Password verification ensures secure account creation.
- Once registered, users can **load balance and subscribe to packages**.

### **2️⃣ Login**
- Grants access to a registered user account.
- Provides three main services:
  - **Balance Inquiry** 💵
  - **Top-up Balance** 📲
  - **Subscribe/Unsubscribe from Packages** 📡
- Users can choose from **Internet, Call, or SMS packages** (Prepaid or Postpaid).

## 🛠 Installation & Usage
### **1️⃣ Install a C++ Compiler**
Ensure you have a C++ compiler installed (like **MinGW, GCC, or MSVC**).

### **2️⃣ Clone the Repository**
```sh
git clone https://github.com/yourusername/Telecommunication-Package-System.git
cd Telecommunication-Package-System
```

### **3️⃣ Compile & Run the Project**
Using **G++ Compiler**:
```sh
g++ main.cpp -o telecom_system
./telecom_system
```
Or, if using **Visual Studio**, open the project and run it.
